📖 DSA Architecture & Viva Reference Guide

1. 2D Orthogonal Range Tree + Fractional Cascading

A 2D Range Tree decomposes planar points on the primary x-axis into a balanced BST. Every internal node keeps an associated array of its subtree points sorted by y-coordinate.

Why Fractional Cascading? Standard 2D range trees require a separate binary search at each of the O(log n) canonical nodes, yielding O(log² n + k) query time. Fractional cascading stores cross-pointers from each parent y-entry into both children's y-arrays. We perform exactly one binary search at the root node, and follow pointers in O(1) time down each canonical node, cutting query time to the optimal O(log n + k).

2. Slab-Decomposition Point Location

Vertical lines passing through zone boundaries divide the plane into vertical slabs. A binary search on x finds the enclosing slab in O(log n) time, followed by binary search on y within the slab. This instantly resolves any incident coordinates to its jurisdiction sector.

3. Dynamic Redistribution Mechanism

When repeated emergencies leave a sector with 0 ambulances, the system locates a donor ambulance from a sector having surplus (>1 available), relocates it to the needy zone's centroid, and rebuilds the 2D Range Tree with updated spatial coordinates in O(n log n) time.
